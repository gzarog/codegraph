title: Next Steps
description: Where to go once your first project is indexed.
---

- **Connect more agents.** [Agent Integrations](/reference/integrations/) lists every supported agent and what the installer changes.
- **Look at the graph.** `codegraph ui` opens the [browser viewer](/guides/viewer/): symbol pages, a module map, screens and steps.
- **Understand the results.** [How It Works](/core-concepts/how-it-works/) and [Resolution & Frameworks](/core-concepts/resolution/) explain what is in the graph and how confident each link is.
- **Run only the tests that matter.** [Affected Tests in CI](/guides/affected-tests/) uses the graph to pick test files for a change.
- **Tune indexing.** [Configuration](/getting-started/configuration/) covers `codegraph.json` and environment variables.
- **Something wrong?** See [Troubleshooting](/troubleshooting/).
