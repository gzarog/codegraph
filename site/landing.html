Local-first code intelligence

Give your coding agent a map of the code.

CodeGraph indexes your project into a knowledge graph of symbols, calls, imports and routes, and hands an agent the exact source it needs in one call instead of a dozen searches. One binary, nothing leaves your machine.

Get started View on GitHub 
curl -fsSL https://raw.githubusercontent.com/gzarog/codegraph/main/install.sh | sh
codegraph init && codegraph install

One call, the right code

codegraph_explore answers "how does login reach the session store" with the source of exactly those symbols, the call path between them, and what depends on them.

Resolved, not guessed

Imports, module paths, receiver types and inheritance turn names into real edges. Name-only matches and dynamic links are marked as such.

Frameworks and dispatch

Routes from 27 frameworks, plus the links code hides: events to listeners, fetch to your own routes, navigations to pages, C function pointers.

Every agent you use

codegraph install configures Claude Code, Cursor, Codex, opencode, Gemini CLI, Kiro, Antigravity, Hermes and GitHub Copilot, editing only its own entry.

See it in the browser

codegraph ui: symbol pages with callers and blast radius, a module map, screens and the conditions between them, steps from any function.

Always current, always local

A shared daemon watches your files and re-indexes in under a second. The graph is a SQLite file in your project; no keys, no services.
